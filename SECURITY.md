# Security

MuK AI Browser lets an AI agent read and act on web pages, so we take reports
about it seriously.

## Supported versions

The version on the Chrome Web Store and the latest GitHub release receive
security fixes.

## Reporting a vulnerability

Please do not open a public issue. Write to **support@mukit.at** with
"Security: MuK AI Browser" in the subject and describe:

- what an attacker can do, and under which conditions;
- the steps or a page that shows it;
- the extension version and, if it matters, the Odoo and `muk_ai_browser`
  versions.

We confirm the report within three working days, keep you posted while we fix
it, and credit you in the release notes unless you prefer otherwise.

Reports about the Odoo app `muk_ai_browser` are welcome at the same address.
